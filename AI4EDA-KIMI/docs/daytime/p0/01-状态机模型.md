# P0 日间学习 01：状态机模型

> 建议用时：20 分钟。对应一生一芯 F4 的核心视角，本单元不需要服务器。
>
> 学完目标：能用“状态 + 状态转移”解释 ISA、模拟器和 RTL 处理器之间的关系。

## 1. 为什么先学状态机，而不是先学指令

处理器看起来由 ALU、寄存器堆、总线和控制信号组成，容易陷入模块细节。换一个视角：处理器的工作就是按照规定，不断把“当前状态”变成“下一状态”。

```text
当前状态 S + 当前指令/输入
          │
          ▼
    ISA 定义的状态转移规则
          │
          ▼
      下一状态 S'
```

同一条规则可以有两种实现：

- 用 C 写出状态转移规则，得到指令集模拟器。
- 用数字电路实现状态转移规则，得到 RTL 处理器。

因此，模拟器和 RTL 不是两个无关项目，而是同一个 ISA 状态机的不同实现。

## 2. ISA 状态是什么

对当前 P0 的迷你 RISC-V 处理器，可以先关注三类**体系结构状态**：

| 状态 | 含义 | 例子 |
|---|---|---|
| PC | 下一条要执行的指令地址 | `pc = 0x80000000` |
| 通用寄存器 | 指令直接读写的运算结果和临时数据 | `x1 = 5` |
| 内存 | 程序和数据所在的存储空间 | `mem[0x1000] = 0x7f` |

后续还会加入 CSR、异常和特权级等状态。现在不用一次学完。

“执行一条指令”可以抽象为：

```text
读取 PC 指向的指令
        ↓
根据 ISA 计算新 PC、新寄存器值或新内存值
        ↓
提交这些变化，形成下一状态
```

ISA 就是软件能观察到的状态集合及其转移规则。它不规定内部必须用几个时钟周期，也不规定必须使用哪种流水线结构。

## 3. 一条指令怎样改变状态

假设当前状态为：

```text
pc = 0x80000000
x1 = 0x00000000
x0 = 0x00000000
mem[0x80000000] 中存放 addi x1, x0, 5
```

`addi x1, x0, 5` 的语义是：

```text
x1 ← x0 + 5
pc ← pc + 4
```

执行后的状态为：

```text
pc = 0x80000004
x1 = 0x00000005
x0 = 0x00000000
```

其他通用寄存器和数据内存保持不变。注意，`x0` 在 RISC-V 中恒为零，写入它不会改变其值。

再看 `sw x1, 8(x2)`。它会计算地址 `x2 + 8`，把 `x1` 的 32 位值写入内存，同时让 PC 前进 4；它不写通用寄存器。这说明不同指令改变的状态部分不同。

## 4. 体系结构状态不等于微架构状态

这是以后学习流水线时很重要的一组区别：

| 类别 | 例子 | 软件是否直接把它当作 ISA 状态观察 |
|---|---|---|
| 体系结构状态 | PC、通用寄存器、内存、CSR | 是 |
| 微架构状态 | 流水线寄存器、分支预测器、缓存标签、内部 valid 位 | 通常否 |

微架构状态会影响性能、时序和内部调试，但不能随意改变指令最终产生的软件可见结果。

例如，同一条 `add` 指令可以由单周期处理器、五级流水线处理器或 C 模拟器执行。它们的内部过程和速度不同，但都应该得到相同的寄存器结果。

## 5. 这个视角怎样帮助调试

如果 DUT 和 REF 从相同初始状态执行相同指令，那么在每条指令的提交边界，两者的体系结构状态应当一致。

假设执行 `addi x1, x0, -1` 后：

```text
REF: x1 = 0xffffffff
DUT: x1 = 0x00000fff
```

不必先翻几千个波形信号。状态差异已经说明问题可能出在立即数符号扩展附近，接下来再有针对性地看译码和扩展电路。

这就是状态机模型与后面 DiffTest 的连接点：**先定义应该一致的状态，再比较状态，最后定位造成差异的内部逻辑。**

## 6. 自测题

先遮住答案，用自己的话回答。

1. 当前迷你 RV 处理器的 ISA 状态至少包括哪三部分？
2. 执行一条普通非跳转指令后，PC 通常怎样变化？
3. 流水线寄存器是否属于 ISA 状态？为什么？
4. 为什么 C 模拟器和 RTL 处理器可以实现同一个 ISA？
5. `sw` 和 `addi` 在“写通用寄存器”这件事上有什么区别？

<details>
<summary>参考答案（先自己回答，再展开）</summary>

1. PC、通用寄存器和内存；后续还会扩展 CSR 等状态。
2. 对 32 位定长指令，通常是 `pc + 4`；跳转等指令会使用自己的目标地址。
3. 不属于。它是具体微架构的内部状态，不是软件依据 ISA 直接观察的结果状态。
4. 因为它们实现的是同一套状态及状态转移规则，只是一个用软件表达，一个用数字电路表达。
5. `sw` 写内存，不写通用寄存器；`addi` 写目标寄存器 `rd`，不写数据内存。

## 7. 无需电脑的思考题

不要写代码，先在纸上或手机备忘录中完成：

1. 为一个只支持 `add/addi/lw/lbu/sw/sb/jalr/lui` 的迷你处理器列出“最小状态清单”。
2. 分别写出 `add`、`lw`、`sw`、`jalr` 会改变清单中的哪些状态。
3. 回答：如果只比较内部波形，而不比较 PC、寄存器和内存，能不能直接证明两条实现符合同一 ISA？为什么？

把你的结论留下来，晚上可以据此设计自己的模拟器状态结构，不要直接照抄一个现成结构体。
